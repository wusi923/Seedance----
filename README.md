# Seedance-E-Commerce-Video

为 [Seedance 2.0](https://jimeng.jianying.com) 视频生成模型撰写电商场景视频提示词的 AI Skill。

基于 40+ 优秀 Seedance 2.0 电商视频案例提炼的最佳实践，覆盖全品类电商视频需求。

## Features

- **12 种电商视频类型**：产品展示、TVC广告、电梯广告、场景混剪、品牌联名、创意特效、ASMR治愈、美食广告、带货短视频、穿搭OOTD、工艺纪录、3D动画
- **精准分镜时间轴**：每种类型都有经过验证的分镜模板和时间分配方案
- **完整词库体系**：镜头语言、材质描述、光影设计、色调定义、转场效果等专业词库
- **物理约束规范**：避免AI生成常见问题（畸变、穿帮、闪烁等）
- **品牌植入规范**：Logo/Slogan/品牌色的最佳植入方式
- **音效BGM设计**：每种视频类型匹配的音效和配乐风格
- **支持垫图模式**：自动标注参考图占位符，引导使用"全能参考"模式
- **Dreamina CLI集成**：一键生成视频

## 12 种电商视频类型

| 类型 | 适用场景 | 典型品类 |
|------|----------|----------|
| A: 产品主图展示 | 电商详情页、主图视频 | 所有品类 |
| B: TVC商业广告 | 品牌宣传片、高端广告 | 奢侈品、汽车、护肤 |
| C: 电梯广告 | 电梯屏、商场大屏 | 家居、医美、大促 |
| D: 场景混剪 | 多场景展示 | 服装、配饰、运动 |
| E: 品牌联名大促 | 618/双11/品牌联名 | 全品类 |
| F: 创意特效 | 社交媒体传播 | 3C、运动、潮玩 |
| G: ASMR/治愈 | 解压/材质展示 | 食品、护肤、家居 |
| H: 美食广告 | 食品饮料展示 | 食品、饮料、茶 |
| I: 带货短视频 | 抖音/小红书种草 | 全品类 |
| J: 穿搭OOTD | 服装展示、换装 | 服装、鞋靴 |
| K: 工艺纪录 | 手工/材质展示 | 皮具、珠宝、家具 |
| L: 3D动画广告 | C4D风格、大促主视觉 | 零食、母婴、护肤 |

## Usage

告诉你的 AI 助手：

```
帮我生成一个 Seedance 电商视频的提示词，产品是 xxx
```

或直接描述你的需求：

```
帮我做一个运动鞋的15秒TVC广告视频提示词
帮我写一个零食带货短视频的提示词
帮我生成一个电梯广告的提示词，主题是春日大促
```
